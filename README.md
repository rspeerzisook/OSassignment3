Cache simulator
Give size of RAM, Cache, and Pages
Give desired memory config, and replacement policy
The simulator inputs a random series of addresses into the simulated cache
A trace file will be returned logging the hits, and misses as well as the hit/miss ratio, and a graph showing the hits/misses over time.

Memory Config Options
1. Direct Mapping
2. Fully Associative
3. K-Way Associative

Replacement Policy Options
1. Prioritize Empty
2. Prioritize Least-Used
3. Prioritize Least-Recently-Used
